# Flappy Bird in Java 🎮
A simple Flappy Bird clone built using Java and Swing.

## Features
✅ Classic Flappy Bird gameplay  
✅ Smooth animations using `javax.swing.Timer`  
✅ Collision detection and scoring  

## How to Run
1. Compile the game:
   ```sh
   javac FlappyBird.java
2. Run the game:
   ```sh
   java FlappyBird
